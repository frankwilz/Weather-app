# Weather by Frank — Mobile

React Native (Expo) mobile app for the weather experience.

## Version Required

- Expo SDK 54

## Run The App

1. Go to the mobile folder:
   ```bash
   cd "weather-app/mobile"
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Add your OpenWeatherMap key:
   ```bash
   EXPO_PUBLIC_OPENWEATHER_KEY=your_openweathermap_key
   ```
4. Start the app:
   ```bash
   npx expo start -c
   ```
   You should see a qr code like this :
   
6. Open on device:
   - Install Expo Go on your phone.
   - Scan the QR code shown in the terminal or DevTools.

If you do not see a QR code, run:
```bash
npx expo start --tunnel
```
